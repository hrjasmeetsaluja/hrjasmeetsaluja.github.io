# Jasmeet Kaur — Interactive Resume (Final)

This is a fully self-contained, free-to-host interactive resume website.

## Open locally
Double-click `index.html` or open it in Chrome/Edge/Safari.

## Files
- `index.html` — website content
- `style.css` — responsive design
- `script.js` — animations, mobile menu and skill tabs
- `assets/jasmeet-kaur.webp` — optimized portrait
- `Jasmeet_Kaur_Master_Resume.pdf` — downloadable master resume

## Free hosting
This folder can be published as-is on GitHub Pages, Netlify or Vercel free tiers.

No paid fonts, libraries, templates or services are required.
